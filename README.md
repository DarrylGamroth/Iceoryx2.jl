# Iceoryx2.jl

Idiomatic Julia bindings for iceoryx2 with full C ABI coverage.

## Install

```julia
julia> ] add https://github.com/DarrylGamroth/Iceoryx2.jl
```

## Quick start

```julia
using Iceoryx2

node = create(NodeBuilder(); service_type = ServiceType.IPC)
service = open_or_create(publish_subscribe(service_builder(node, "Demo/Service"), UInt64))

pub = create(publisher_builder(service))
sub = create(subscriber_builder(service))

sample = loan!(pub)
write_payload!(sample, UInt64(42))
send!(sample)

recv = receive!(sub)
value = payload(recv)[1]
close(recv)
```

## Examples

See `examples/` for publish/subscribe, request/response, event, and blackboard samples that match the upstream C++ examples.

## Cross-language type names

For custom payloads/headers/keys used across languages, define a stable type name:

```julia
Iceoryx2.type_name(::Type{MyType}) = "MyType"
```
